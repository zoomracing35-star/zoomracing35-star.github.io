# ZoomRacing · Октябрьский Time Attack — лайв-тайминг

Статический сайт для GitHub Pages. Читает реальные октябрьские результаты из Google Таблицы каждые 10 секунд. Сборка, платный сервер и API-ключи не нужны.

## Что показывает

- Октябрьский раздел таблицы «TIME ATTACK зачет»: Porsche 911 GT3 R, Red Bull Ring GP.
- Имя участника, лучшее время, место, отставание от лидера и баллы.
- Поиск по участникам, ручное и автоматическое обновление.
- Время последнего успешного чтения. При ошибке остаются последние полученные результаты с явным предупреждением.
- Адаптивный интерфейс для телефона и компьютера.

Места вычисляются по времени по возрастанию. Одинаковое время даёт одинаковое место (1, 1, 3). Отставание рассчитывается с точностью до миллисекунды. Баллы берутся из колонки J без пересчёта. DNS и пустые/неправильные времена остаются в конце без места и отставания.

## Данные и доступ

Используется исходная таблица, лист `Лист1`, `gid=0`. Запрос `select A,G,J` получает только имена, время и баллы. После чтения выбирается раздел от строки «ОКТЯБРЬ» до следующего месяца. Новые участники внутри этого раздела появляются автоматически. Другие колонки в браузер не загружаются.

Таблица должна быть доступна для чтения всем, у кого есть ссылка. Исходная таблица не изменяется. Код сайта и адрес источника видны посетителям и в публичном репозитории.

Проверка каждые 10 секунд — интервал запросов. Google не гарантирует появление каждой правки за 10 секунд. Подпись «Проверено» означает время успешного запроса, а не время последней правки организатора. Во время скрытой вкладки запросы приостанавливаются; при возвращении данные запрашиваются сразу.

## Бесплатная публикация на GitHub Pages

Репозиторий для публикации: [zoomracing35-star/zoomracing35-star.github.io](https://github.com/zoomracing35-star/zoomracing35-star.github.io). Целевой адрес сайта после успешной публикации: [https://zoomracing35-star.github.io/](https://zoomracing35-star.github.io/).

1. В аккаунте **zoomracing35-star** создайте **публичный** репозиторий с точным названием `zoomracing35-star.github.io`, если он ещё не создан.
2. Загрузите содержимое этой папки в корень репозитория: `index.html` должен лежать в корне, а не внутри вложенной папки. Не загружайте ZIP вместо файлов.
3. Откройте **Settings → Pages**.
4. В **Build and deployment → Source** выберите **Deploy from a branch**.
5. Выберите ветку **main**, папку **/(root)** и нажмите **Save**.
6. Дождитесь успешной публикации. GitHub покажет адрес `https://zoomracing35-star.github.io/` — сайт открывается в корне адреса, без имени репозитория в пути.

Файл `.nojekyll` позволяет публиковать сайт без обработки Jekyll. Все пути относительные, поэтому логотип, шрифты и скрипты загружаются относительно корня сайта.

## Настройки

Файл `config.js`: заголовок и описание, ссылка на источник, лист, интервал запросов и часовой пояс. Для этой таблицы сохраняйте `query: "select A,G,J"`, `headerRows: 0`, `transform: "october"` и диапазон, включающий начало следующего месяца.

Если организатор поменяет структуру колонок, нужно обновить запрос и сопоставление в `model.js`. Изменение значений результатов в текущей структуре не требует изменения сайта или повторной публикации.

## Дизайн ZoomRacing

Цвета из брендбука: фиолетовый `#2F00FF`, черный `#000000`, белый `#FFFFFF`. Оригинальный белый логотип извлечён из предоставленного брендбука, без перерисовки.

Основной шрифт брендбука — **EuropeExt**. PDF содержит контуры отдельных символов, не полноценный файл шрифта. CSS использует локальный EuropeExt, если он установлен у посетителя; пока используется бесплатный шрифт **Unbounded** для заголовков как временная замена. Он не является EuropeExt. Веб-файл EuropeExt необходимо добавить отдельно: загрузить `EuropeExt.woff2` и заменить `src` первого `@font-face` на `url("EuropeExt.woff2") format("woff2")`. Лицензия Unbounded находится рядом с файлом шрифта.
