# Подключение Google Таблицы

Сайт читает таблицу прямо из браузера. Сервер, платный тариф и API-ключ не требуются.

1. Создайте отдельную Google Таблицу для результатов, которые должны быть видны зрителям.
2. Откройте «Настройки доступа» / «Поделиться». В разделе общего доступа выберите «Все, у кого есть ссылка» и роль «Читатель».
3. Откройте нужный лист и скопируйте обычную ссылку из адресной строки: `https://docs.google.com/spreadsheets/d/ID/edit#gid=0`.
4. Укажите её в настройках сайта. Если `gid` задан отдельно, он определяет лист; иначе используется `gid` из ссылки, затем `0`.
5. Первая строка должна содержать названия колонок. Одна следующая строка — один участник. Изменение данных в таблице будет видно после очередного обновления страницы сайта.

Публикация через меню «Файл → Поделиться → Опубликовать в интернете» для этого способа не нужна. Ссылки опубликованной версии `/d/e/2PACX-…/pubhtml` адаптер не принимает: используйте ссылку исходной таблицы `/d/ID/edit`.

Таблица доступна любому, кто знает ссылку. Для показа публикуйте только нужные зрителям данные. Ограничение диапазона на сайте определяет, какие ячейки он запрашивает, и не меняет права доступа к таблице.

## Время и результаты

Для времени круга или финиша удобнее использовать текстовые ячейки, например `01:23.456`. Если Google возвращает оформленное значение ячейки (`f`), сайт сохраняет его без изменений. В том числе сохраняются ведущие нули и формат длительности. При отсутствии `f` используется значение `v`. Полностью пустые строки пропускаются.

В одном столбце используйте один тип данных. При смешении типов запрос Google может вернуть пустые значения для ячеек другого типа. Например, для колонки с временем и значениями `DNS` / `DNF` лучше заранее выбрать в таблице «Формат → Числа → Обычный текст». [Google описывает это поведение запросов](https://support.google.com/docs/answer/3093343?hl=ru).

Опрос таблицы даёт обновления с задержкой: интервал запроса сайта и обработка Google не гарантируют точность до долей секунды. Тайминг показывает опубликованные в таблице результаты.

## Контракт модуля

После подключения `sheets.js` доступен `window.TimingSheets`:

```js
const source = TimingSheets.parseSource(sheetUrl, gid);
// { id: "ID исходной таблицы", gid: "0" }

const data = await TimingSheets.read({
  sheetUrl: "https://docs.google.com/spreadsheets/d/ID/edit#gid=0",
  gid: "0",              // необязательно; имеет приоритет перед gid из ссылки
  range: "A1:Z1000",      // необязательно; значение по умолчанию
  query: "select A,G,J",  // необязательно; запросить только нужные колонки
  headerRows: 1,          // необязательно; первая строка становится заголовками
  timeoutMs: 12000        // необязательно; ожидание ответа
});
// { columns: [{ id, label, type }], rows: [["1", "Участник", "01:23.456"]] }
```

`parseSource` принимает обычную HTTPS-ссылку `docs.google.com/spreadsheets/d/ID` или сам ID. `gid` читается из query-параметров или фрагмента ссылки; отдельно заданный непустой `gid` переопределяет их. Для запроса используется только проверенный домен Google.

`range` задаётся ограниченным A1-диапазоном, например `A1:H500` или `B2`. Максимум — 100 000 ячеек. `headerRows` — целое число от нуля; `timeoutMs` — от 1 до 120 000 миллисекунд. `read` возвращает Promise; неверные настройки, отказ в доступе, ошибка Google, отсутствие ответа или сетевая ошибка отклоняют его с понятным сообщением на русском. Пустая таблица возвращает пустой массив строк.

`query` передаёт запрос Google Visualization через параметр `tq`. Например, `select A,G,J` исключает остальные колонки из ответа Google, даже если они находятся внутри `range`. В таблице с вертикальными блоками нескольких событий используйте `headerRows: 0`, чтобы первая строка не превращалась в заголовок. Если первая строка диапазона — обычные заголовки, используйте `headerRows: 1`.

При обработке ответа модуль удаляет временный script и таймер. Запросы имеют разные обработчики; поздний ответ завершённого запроса безопасно игнорируется. Отображайте значения через `textContent`, поскольку содержимое таблицы — обычный текст.
